# Atlas v0.1.0 para Windows

Esta é a primeira prévia pública do Atlas, um navegador nativo baseado no Chromium.

## Destaques

- Chromium 154.0.8031.0 para Windows x64.
- Identidade visual Atlas aplicada ao executável e à interface.
- Tema escuro e abas verticais ativados para perfis novos.
- Atalhos laterais começam vazios e são definidos pelo usuário.
- Google configurado como mecanismo de busca padrão, podendo ser alterado nas configurações.
- Recursos nativos do Chromium, incluindo DevTools, histórico, gerenciador de downloads e suporte a extensões compatíveis.
- Identidade de instalação própria para separar o Atlas do Chromium: perfil, protocolo, ProgIDs, registros COM e sandbox.

## Instalação

Baixe `Atlas-Setup-0.1.0-win-x64.exe` e execute o instalador. O pacote é destinado ao Windows 64 bits.

O arquivo `SHA256SUMS.txt` permite conferir a integridade do download.

## Estado desta prévia

- O executável ainda não possui assinatura digital; o Windows SmartScreen pode exibir um aviso.
- A infraestrutura de atualização automática ainda será implementada e validada em uma versão futura.
- Widevine/DRM e a reprodução em serviços como Netflix e Crunchyroll ainda não foram validados nesta prévia.
- Esta versão é de desenvolvimento e ainda não é recomendada como navegador principal.
