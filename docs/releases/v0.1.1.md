# Atlas v0.1.1 para Windows

Esta prévia atualiza a interface nativa do Atlas sobre o Chromium 154 para aproximar a navegação vertical do fluxo definido para o projeto.

## Alterações

- Sidebar nativo com navegação, endereço, workspaces, guias essenciais e guias comuns em uma única superfície.
- Rodapé do sidebar fixado corretamente na base, com acesso a downloads e criação de workspace.
- Workspace ativo identificado no sidebar e sincronizado com os grupos de guias do Chromium.
- Separação visual entre guias essenciais fixadas e guias comuns, inclusive quando a área de essenciais está vazia.
- Atalhos para alternar workspaces com `Ctrl+Alt+Q` e `Ctrl+Alt+E`.
- Controles da janela ajustados ao layout lateral e ao comportamento maximizado/restaurado.
- Identidade, ícones e versão próprios do Atlas mantidos separados da versão interna do Chromium.
- Importação local experimental de Widevine preservada para testes pessoais, sem redistribuir o CDM.

## Instalação

Baixe `Atlas-Setup-0.1.1-win-x64.exe` e execute o instalador no Windows 64 bits.

Use `SHA256SUMS.txt` para conferir a integridade do arquivo baixado.

## Observações

- O instalador ainda não possui assinatura digital; o Windows SmartScreen pode exibir um aviso.
- O suporte a serviços protegidos por DRM depende de uma instalação válida e licenciada do Widevine e pode variar conforme as exigências de cada plataforma.
- Esta versão continua sendo uma prévia de desenvolvimento.
