# Identidade Atlas

Arquivos oficiais recebidos para a identidade visual do navegador.

- `mark.svg`: fonte vetorial canônica para ícones e recursos funcionais;
- `app-icon-dark.svg`: variante principal do aplicativo sobre `Night`;
- `app-icon-light.svg`: variante para superfícies claras;
- `identity-guide.png`: prancha de identidade visual v1.0;
- `logo-glow.png`: arte institucional de alta resolução.

## Regras de uso

- preservar a geometria original do símbolo;
- manter o gradiente vertical `Cyan → Azure → Blue → Indigo → Violet`;
- usar a versão sem glow, neon ou efeito 3D em ícones e controles;
- reservar `logo-glow.png` para abertura, apresentação ou divulgação em tamanho
  grande;
- usar `Inter Display` em títulos de marca e `Inter` na interface quando a
  plataforma disponibilizar essas famílias.
